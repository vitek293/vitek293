# Установка на Xiaomi Mi Box / Mi TV Stick (Android 9)

Ваша приставка: **Xiaomi, Android 9 (API 28)**. APK лаунчера подходит —
`minSdk 21`, `targetSdk 34`, проверки версии не будет.

Есть одна важная особенность Xiaomi: **кнопка Home на пульте привязана к
PatchWall**, а не к системному выбору лаунчера. Поэтому сценарий «поставить
приложение и нажать Home» на Mi Box сам по себе не сработает — нужно один раз
переключить домашний экран через ADB (или через настройки, см. ниже).
В самом лаунчере для этого есть плитка **«Дом»** в ряду «Система».

---

## Шаг 0. Проверьте точную модель

**Настройки → Об устройстве** — там будет `Mi Box S`, `Mi Box 3/4`,
`Mi TV Stick` (MDZ-22-AB / MDZ-24-AA / MDZ-27-AA и т.п.).
Пакет PatchWall зависит от модели:

| Модель | Пакет PatchWall |
|---|---|
| Mi Box (международный, Android TV 8/9) | `com.mitv.tvhome.atv` |
| Mi TV Stick (международный) | `com.mitv.tvhome.atv` |
| Китайская прошивка | `com.mitv.tvhome` |
| Глобальная прошивка с Google TV | `com.google.android.tvlauncher` |

Если сомневаетесь — команда ниже покажет установленные лаунчеры, и вы
выберете нужный из списка.

## Шаг 1. Включите отладку

1. **Настройки → Об устройстве (Device Preferences → About)** →
   нажмите **7 раз** на **Номер сборки (Build)** → «Вы стали разработчиком».
2. **Настройки → Настройки устройства → Для разработчиков
   (Device Preferences → Developer options)**:
   - включите **Отладка по USB (USB debugging)**
   - **Отладка по сети / ADB по сети** — на Android 9 у Mi Box её может
     не быть в меню; тогда ADB включится командой `adb tcpip 5555` (шаг 2b).

## Шаг 2a. Подключение по сети (если пункт есть)

IP приставки: **Настройки → Сеть и интернет → ваша сеть → IP-адрес**
(например `192.168.1.42`).

```bash
adb connect 192.168.1.42:5555
adb devices
```

На экране ТВ появится запрос «Разрешить отладку?» — отметьте «Всегда
разрешать» и нажмите **ОК**.

## Шаг 2b. Если отладки по сети в меню нет

Нужен один раз кабель **USB A–A** (male-to-male) от приставки к компьютеру:

```bash
adb devices          # приставка должна появиться
adb tcpip 5555       # переключить ADB на сеть, кабель можно отключить
adb connect 192.168.1.42:5555
```

> После каждой перезагрузки приставки ADB по сети пропадает —
> повторите `adb tcpip 5555` по кабелю. Для установки одного APK
> это не проблема.

## Шаг 3. Установите лаунчер

```bash
adb install -r app-debug.apk
```

`Success` — приложение на месте, оно появится в списке приложений
(и в самом лаунчере, и в PatchWall).

## Шаг 4. Сделайте его домашним экраном

### Вариант А — через ADB (надёжный, для Mi Box)

Сначала посмотрите, какой лаунчер сейчас главный:

```bash
adb shell cmd shortcut get-default-launcher
# либо просто посмотрите список:
adb shell pm list packages | grep -i -E "launcher|tvhome"
```

Затем:

```bash
# 1. Указать наш лаунчер домашним
adb shell cmd package set-home-activity com.vitek.tvlauncher/.MainActivity

# 2. Отключить PatchWall (замените пакет на ваш из таблицы в шаге 0)
adb shell pm disable-user --user 0 com.mitv.tvhome.atv

# 3. Если на вашей модели Home всё ещё уходит в Google-лаунчер:
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

Проверка: нажмите **Home** на пульте — должен открыться тёмный экран
с рядами «Топ / Приложения / Система».

**Откат в любой момент** (приставка не «окирпичивается», все изменения
обратимы):

```bash
adb shell pm enable --user 0 com.mitv.tvhome.atv
adb shell pm enable --user 0 com.google.android.tvlauncher
```

### Вариант Б — без ADB, через настройки

Плитка **«Дом»** в ряду «Система» открывает системный экран выбора
домашнего приложения. На многих прошивках Mi Box там можно выбрать
**TV Launcher** и «Всегда». Если выбор не появляется или Home всё равно
уводит в PatchWall — используйте вариант А.

### Вариант В — совсем без компьютера

Поставьте APK с флешки (см. основной `README.md`), откройте лаунчер,
плитка **«Дом»** → выберите TV Launcher. Если PatchWall не отдаёт Home —
без ADB, к сожалению, никак: это ограничение прошивки Xiaomi.

## Управление на пульте Mi Box

| Кнопка | Действие |
|---|---|
| Кольцо D-pad | Перемещение между плитками |
| OK | Открыть приложение |
| OK (удерживать ~полсекунды) | Меню: закрепить в топе / удалить |
| Назад (Back) | Закрыть меню |
| Home | Возврат на лаунчер (после шага 4) |

На пульте Mi Box есть ещё **кнопка питания** и **Google Assistant** —
они продолжают работать как раньше, лаунчер их не перехватывает.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `adb: no devices found` | проверьте, что ТВ и компьютер в одной сети; включите отладку по USB; попробуйте `adb kill-server` и снова `adb connect IP:5555` |
| `unauthorized` | на экране ТВ не подтвердили запрос отладки — отключите и включите отладку, повторите `adb connect`, нажмите «ОК» на ТВ |
| `Failure [INSTALL_FAILED_...]` | обычно старая версия приложения: `adb uninstall com.vitek.tvlauncher` и установите заново |
| Home уводит в PatchWall | шаг 4, вариант А, пункт 2 |
| Home открывает чёрный экран | отключён не тот лаунчер: `adb shell pm enable --user 0 com.google.android.tvlauncher`, затем повторите `set-home-activity` |
| Хочу вернуть как было | выполните блок «Откат» из шага 4 и удалите приложение: `adb uninstall com.vitek.tvlauncher` |
