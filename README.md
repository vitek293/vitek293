# TV Launcher в стиле Apple TV (tvOS)

Лаунчер для телевизоров на **Android TV / Google TV** в стиле Apple TV:
тёмный фон с мягким параллаксом, ряды приложений, большие плитки «Топ»,
плавное увеличение сфокусированной плитки при навигации с пульта.

## Что умеет

- Все установленные приложения — в одном ряду, с иконками и названиями
- Ряд **«Топ»** (как Top Shelf в Apple TV) с большими плитками — закрепляйте любимые приложения
- Ряд **«Система»**: Настройки, Поиск, Play Маркет
- Часы и дата в шапке (на языке системы)
- **Долгое нажатие** на плитку (удерживать OK на пульте) — меню:
  закрепить в топе / убрать из топа / удалить приложение
- Полное управление с пульта (D-pad); мышь и тач тоже работают
- Работает как полноценный домашний экран: нажатие Home открывает его

## Как получить APK

Сборка настроена в `ci/github-actions-build.yml`. Чтобы включить её:

1. В репозитории создайте папку `.github/workflows/` и положите туда
   файл `ci/github-actions-build.yml` (GitHub выполняет только файлы из
   `.github/workflows/`).
2. Сделайте коммит — сборка запустится автоматически (или вручную:
   вкладка **Actions → Build APK → Run workflow**).
3. Откройте последний запуск **Build APK** и скачайте артефакт
   **tv-launcher-debug** — внутри `app-debug.apk`.

Собрать самому:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (проще всего — открыть проект в Android Studio
и нажать Run; студия сама скачает нужный SDK).

## Установка на телевизор

### Вариант 1 — через ADB по сети (самый быстрый)

1. На ТВ включите режим разработчика:
   **Настройки → О телевизоре (System → About)** — 7 раз нажмите на
   **Номер сборки / Build**.
2. **Настройки → Система → Параметры разработчика → Отладка по сети
   (Network debugging / ADB over network)** — включите и запомните IP-адрес
   (например `192.168.1.42`).
3. На компьютере установите [platform-tools](https://developer.android.com/tools/releases/platform-tools)
   и выполните:
   ```bash
   adb connect 192.168.1.42:5555
   adb install -r app-debug.apk
   ```
   Если ТВ попросит подтвердить подключение — разрешите на экране телевизора.

### Вариант 2 — с флешки (без компьютера)

1. Скопируйте `app-debug.apk` на USB-флешку (FAT32).
2. Вставьте флешку в ТВ. Откройте любой файловый менеджер
   (например, «File Commander» или «X-plore» из Play Маркета).
3. Запустите APK и разрешите установку из неизвестных источников,
   когда система спросит.

### Вариант 3 — через приложение-помощник

«Send files to TV» (на ТВ из Play Маркета, на телефоне — из его стора):
передайте APK на ТВ и откройте его в файловом менеджере.

## Сделать лаунчером по умолчанию

Нажмите кнопку **Home** на пульте — Android предложит выбрать главный экран.
Выберите **TV Launcher** и нажмите «Всегда» / «Use as default».
Готово: теперь Home всегда возвращает на этот экран.

Если окно выбора не появилось (ТВ запомнил старый лаунчер):
**Настройки → Приложения → Показать системные → TV Launcher →
«Запуск по умолчанию» → Очистить** — затем снова нажмите Home.

## Управление

| Кнопка | Действие |
|---|---|
| Стрелки / D-pad | Перемещение между плитками и рядами |
| OK (коротко) | Открыть приложение |
| OK (удерживать ~0.5 с) | Меню: закрепить в топе / убрать / удалить |
| Назад | Закрыть меню |

## Важно про модель ТВ

APK ставится на **Android TV**, **Google TV** и большинство приставок
(Chromecast с Google TV, Xiaomi Mi Box/Stick, Nvidia Shield, телевизоры
Sony, Philips, TCL, Hisense и др.).

- **Samsung (Tizen)** и **LG (webOS)** — APK не подойдёт, там другая ОС.
- Если у вас не Android TV, но есть HDMI-приставка на Android — лаунчер
  ставится на приставку и будет открываться вместе с ней.

## Структура проекта

```
app/src/main/java/com/vitek/tvlauncher/
├── MainActivity.kt          # точка входа, полноэкранный Compose-контент
├── LauncherViewModel.kt     # список приложений + закреплённые (SharedPreferences)
├── data/TvApp.kt            # модель приложения, рендер иконки в Bitmap
└── ui/
    ├── LauncherScreen.kt    # экран: шапка, ряды «Топ» / «Приложения» / «Система»
    ├── AppTile.kt           # плитки: квадратная, широкая Top Shelf, системная
    └── AppContextDialog.kt  # меню по долгому нажатию
```
