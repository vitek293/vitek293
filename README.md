# TV Launcher в стиле Apple TV (tvOS)

Лаунчер для телевизоров на **Android TV / Google TV** в стиле Apple TV:
тёмный фон с мягким параллаксом, ряды приложений, большие плитки «Top Shelf»,
плавное увеличение сфокусированной плитки при навигации с пульта.

## Что умеет

- Все установленные приложения — в одном ряду, с иконками и названиями
- Ряд **«Топ»** (Top Shelf) с большими плитками — закрепляйте любимые приложения
- Ряд **«Система»**: Настройки, Поиск, Play Маркет
- Часы и дата в шапке (на языке системы)
- Долгое нажатие на плитку (удерживать кнопку OK пульта) — меню:
  закрепить в топе / убрать из топа / удалить приложение
- Полностью управление с пульта (D-pad), мышь/тач тоже работают

## Как получить APK

APK собирается автоматически в GitHub Actions при каждом пуше:

1. Откройте вкладку **Actions** в этом репозитории
2. Выберите последний запуск **Build APK**
3. Скачайте артефакт **tv-launcher-debug** (файл `app-debug.apk`)

## Установка на телевизор

### Вариант 1 — через ADB (по сети)

1. На ТВ: **Настройки → О телевизоре** — несколько раз нажмите на номер сборки,
   чтобы включить **режим разработчика**. Затем **Настройки → Система →
   Параметры разработчика → Отладка по сети** — включите, запомните IP ТВ.
2. На компьютере:
   ```bash
   adb connect <IP_ТЕЛЕВИЗОРА>
   adb install app-debug.apk
   ```

### Вариант 2 — с флешки

Скопируйте APK на флешку, вставьте в ТВ и откройте через любой файловый
менеджер (если нет — установите, например, «File Commander» из Play Маркет).
Разрешите установку из неизвестных источников, когда система спросит.

## Назначение лаунчером по умолчанию

После установки нажмите кнопку **Домой** на пульте — система предложит выбрать
главный экран. Выберите **TV Launcher** и отметьте «Всегда» / «Использовать
по умолчанию». Дальше лаунчер будет открываться при нажатии Home.

> Если ТВ на Samsung (Tizen) или LG (webOS) — этот APK не подойдёт,
> для них нужен другой подход. Напишите, и адаптирую.

## Управление

| Кнопка | Действие |
|---|---|
| Стрелки D-pad | Перемещение по плитке |
| OK (коротко) | Открыть приложение |
| OK (удерживать) | Меню: закрепить в топе / удалить |
| Назад | Закрыть меню (на главном экране — ничего) |
| Домой | Вернуться на главный экран |

## Сборка локально

Нужны JDK 17 и Android SDK. Открыть проект в Android Studio и нажать Run,
либо из командной строки:

```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
